# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 3.x     | Yes       |
| < 3.0   | No        |

Security fixes are prepared primarily for the current stable version. This
table does not constitute a commitment to long-term support for every future
3.x release.

## Reporting a Vulnerability

Do **not** report security vulnerabilities through public GitHub Issues. Use
[GitHub Private Vulnerability Reporting](https://github.com/krzymianowski/EtykietyIT/security/advisories/new)
for this repository instead. Do not publish proof-of-concept code or exploit
details before a fix is available.

Please include as much of the following information as possible:

- affected Etykiety IT version,
- Windows version,
- application mode: Standard or Portable,
- a description of the vulnerability,
- steps to reproduce it,
- potential impact,
- optional logs or screenshots that do not contain sensitive data,
- a suggested mitigation, if known.

Reports in English or Polish are welcome.

## Security Scope

Relevant security issues include, for example:

- unsafe file or path handling,
- arbitrary file overwrite,
- sensitive data exposure,
- code execution,
- dependency vulnerabilities,
- privilege or security boundary issues.

Ordinary functional defects should be submitted through the
[Bug report form](https://github.com/krzymianowski/EtykietyIT/issues/new?template=bug_report.yml).
